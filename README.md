# CobbleRouge 배포 파일

CobbleRouge 런처가 받아 가는 배포 파일만 두는 저장소입니다. 소스 코드는 없습니다.

- `pack-<버전>` 릴리스: 모드팩 배포 목록 `manifest.json`과 서명 `manifest.json.sig.json`
- `mod-v<버전>` 릴리스: Cobblemon Roguelike 모드 JAR

여기서 파일을 직접 내려받지 말고 **CobbleRouge 런처**로 설치·업데이트하세요. 런처가 서명과 파일 해시를 확인합니다.
다른 모드(Cobblemon, Fabric API 등)는 이곳에 올리지 않고 Modrinth에서 받습니다.
